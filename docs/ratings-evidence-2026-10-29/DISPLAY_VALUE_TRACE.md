## Data-to-card path

1. **Raw canonical inputs.** The source tree is `data/canonical/universe_2026_27_offseason.json` (`meta.starting_data_version=2026-10-30-contract-separation-v10`; talent model 2; offense model 1). The canonical rating/roster snapshot date is July 28, 2026. The dossier's four OVRs came from `player_attribute_summary`, not from a stored OVR field. The v10 contract import resolution is a separate later data update; see the current Lillard payload below.
2. **New-save baseline.** `create_league_save()` in `src/nba_gm_data/save.py` stores the source `canonical_hash` and `starting_data_version`, copies canonical health states into the save, and initializes development totals/events empty. A matching current baseline is selected for this version. There is no new-save player development event. The save's initial rotation state is built from canonical display-minute projections.
3. **Runtime view.** `canonical_with_save()` overlays save-owned state and calls `apply_save_rotation_projection()`. This updates each player's `minutes_projection` from the saved rotation. `player_attribute_summary()` includes `min(6, minutes / 7)` in the overall formula (and role blending when the talent model is enabled), so rotation minutes can change engine OVR. In the October 20 disposable save, saved baseline minutes are Lillard 20.0, Harper 22.1, Sochan 25.0 and Dončić 30.0; automatic rotation projects 21.47, 15.89, 26.84 and 31.87 minutes respectively. These are rotation effects, not health penalties.
4. **Engine summary.** `player_attribute_summary()` computes `shooting`, `creation`, `defense`, `athleticism`, `iq`, `rebounding`, and related fields from canonical traits; when talent is enabled, it blends its weighted overall with the position-role skill value. With offense enabled, it also returns `offense` and offensive facets. These are game engine values on the compressed internal scale.
5. **Presentation transform.** `player_display_attribute_summary()` maps every engine summary field through `presentation_rating_value()`. The fixed piecewise anchors are `(1,25), (20,36), (30,48), (40,60), (50,70), (60,80), (70,88), (80,95), (90,98), (99,99)`, linearly interpolated and rounded to one decimal. No percentile or league-wide normalization is used for this player value.
6. **App action.** Dispatch for `player_card` in `src/nba_gm_data/app_actions.py` calls `player_card_payload()`. It calculates `attrs = player_display_attribute_summary(active, player_id)` and returns them in `payload.ratings`; the payload does not set top-level `overall`, `offense`, or `defense` keys. Health risk is a separate payload field, not a multiplier in this rating computation.
7. **Frontend.** `playerSummaryRatings()` in the UI prefers top-level `player.overall/offense/defense` if present, then falls back to `player.ratings.overall/offense/defense`; because the app-action response only returns the nested `ratings` fields, the displayed headline fields are `ratings.overall`, `ratings.offense`, and `ratings.defense`. The UI's fallback for offense is an average of shooting/creation/passing only when no `offense` field is present; it is not used when the offense-enabled canonical action provides that key.

### Source-to-runtime differences

Rotation minutes explain the changed engine OVRs relative to the canonical source summary: Lillard 68.5 → 68.0, Harper 59.5 → 58.6, Sochan 56.9 → 59.1, Dončić 71.3 → 70.8. Canonical projection, saved rotation baseline and live runtime projection are distinct inputs. Sochan's runtime projection is 26.84 versus a saved baseline of 25.0; this raises his workload contribution. The other three runtime projections are below their saved baselines and lower their workload contribution. OFF and DEF remain unchanged because this rotation adjustment affects the OVR workload term, not their trait-derived component summaries.

The fixed presentation transform then accounts for the gap between engine and card ratings: e.g. Sochan engine OVR 59.1 becomes card OVR 79.1, and Luka 70.8 becomes 88.6. These are distinct scales, not a display bug. The current card OVRs are not the same as the previous July-start probe's 86.5/78.6/75.3/88.3, because that probe had a different active rotation projection (22.4/15.89/0.0/30.4 minutes). It showed Sochan at zero minutes, an earlier rotation outcome, not an injury. The earlier artifact `probe_artifacts/player_card_probe_20261030.json` and its disposable save are retained as historical evidence; the October 20 entry-point result above is the current trace.
