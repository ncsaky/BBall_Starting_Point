[Compiler audit](../output/pick-and-pop-2026-11-15/verified/compiler-dependency-audit.json).

This is a partial C17/C18/C19/R11 chain, not a new skill or a finished role grade:

- **Call, preference and read:** the tactical call can request a route or use the full T11 distribution. The new consumer retains pop mass, including all-pop distributions; it never conditions pop away. S28 independently gates the read and existing follow-up release delay. A missed intended pop holds the screen and offers other noticed actions/reset, rather than inventing a roll or a successful pop. A zero-pop preference can still receive a separately declared coaching call; that does not rewrite innate preference.
- **Relocation and coverage:** legal screen geometry/contact still uses S27, body/capacity and guard navigation. A pop releases after its screen phase, with a bounded S26/P09 settling delay, then travels using actual acceleration/speed to a separately supplied perimeter destination. The receiver must reach that destination before presenting the pop catch. Defender stay/show recognition and movement derive a finite closing window. The receiver can remain at the endpoint while the defender continues recovering; the window is not held open.
- **Pass semantics:** candidate `pop` uses **F06 recognition/execution** because this bounded context delivers from the same-side drive exit to the perimeter. It is distinct from the fixed `F06` outlet and cannot coexist as F03/F04 for the same pop route. The family is applied once, never summed with F01 or F03. The existing F06 notice draw is shared across the two same-family outlets; independent per-target recognition is not claimed. A cross-court pop and stationary F01 return/connector context remain unsupported.
- **Receiving and shooting:** the actual moving catch, placement quality, S14 reception gate/preparation, S08 release, S09 distance extension and S01 catch execution feed the existing shot function once. Actual pop coordinates set both shot distance and geometry; the old deployment point does not substitute for them. Willingness shapes availability/selection, not physical accuracy. S26 creates timing, not an extra shooting or gravity bonus.
- **Closeout and scoring:** the assigned primary defender continues its path through launch, flight and catch; its actual remaining travel and S40 control determine arrival/pressure in the shared shooting response. Fouls/FT, make/miss, reception, clock and accounting use the shared event kernel. Full C37 geometry/contest/foul technique is still incomplete; this task does not claim a new perimeter-block or foul model. C27 is not misapplied as an extra full perimeter bonus.

## Early-window audit and paid delay

The [authenticated reproduction](../output/pick-and-pop-2026-11-15/verified/early-window-reproduction.json) uses the accepted Curry/Jokić scene. Current legacy behavior matches that frozen record exactly.

In the opt-in timing experiment, the same Jokić source grades and T11 are retained; only an explicit S26 capability completion is added, and S26 is unused on this roll. Immediate mode still has no feed. Bounded-wait mode finds F03/F04, charging **.198832s wait**, pressure .632585 and conditional extra handling loss .009638. Conditional F03 branches include inaccurate delivery .585650, late delivery .022062, failed catch .158520 and waiting loss .009638. Later eligibility is not a promised successful pass.

The new solver performs at most12 deterministic interception updates and selects the earliest feasible minimum-delay catch in the finite window. Actual delivery error still moves catch time/position and may expire the chance. The ball is held at the declared drive exit; primary recovery raises pressure with wait duration, placement is recomputed under that pressure, and a duration-based conditional handling hazard is sampled with reserved preallocated draw43. Initial handling was already sunk and is not charged twice. Receiver and coverage kinematics advance; existing committed help is carried forward. This is a single observed help/read and a bounded hold, not a future rotation or multi-step possession planner.

The projector integrates that wait hazard analytically, then the same actual pass/catch/shot branches. Clock precedence includes waiting, flight, catch and release. Truly expired stay windows remain unavailable; a short clock can make an available candidate worthless. Old callers do not receive delayed eligibility automatically. The accepted G4/G8 quadrature, imperfect reads/choice, bounded reset proxy and zero rebound continuation credit remain.
