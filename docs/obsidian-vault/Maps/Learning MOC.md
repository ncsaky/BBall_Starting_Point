- [[Learning/Self-Test Questions]] - prompts that test whether the mental model is really internalized.

## Learning Loop

1. Read one system note.
2. Follow its source links and identify the authoritative state.
3. Find its tests and state the invariant each one protects.
4. Explain one rejected alternative and why it might become right later.
5. Run or instrument a small deterministic scenario.
6. Add a link or correction when reality differs from the note.

The goal is not memorizing 50,000 lines. It is learning the handful of models and boundaries that make those lines coherent.
