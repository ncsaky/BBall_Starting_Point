The prior one-panel method lost narrow `recovery_defended` branches, including the Towns clock case. Its small value changes could also change which action received the existing bad-choice probability. This design therefore does not infer an empty region from matching endpoints, a few probes or agreement between two quadratures. It also does not smooth the imperfect-choice rule.

One separately named experiment, `certified_interval_recovery_v1`, retains every optimized-reference radial/angular node, weight and accumulation order. It attempts to bypass full resolution only in terminal regions that a conservative physical bound certifies:

1. Start from the reference's four radial-CDF panels in each of six directions. Across an entire error interval and time0 through the full recovery horizon, enclose the affine horizontal ball trajectory in its swept rectangle.
2. Distance from the receiver to that rectangle is a lower bound on distance to every possible point in the interval. Grant the maximum horizontal reach and full horizon for receiver travel, with no vertical/takeoff constraint. If even this optimistic access fails, no narrow interior recovery island can exist. Spatial/time padding conservatively covers rounding in the represented dimensional range.
3. If the bound is inconclusive, split the CDF interval at its midpoint, to depth2 and at most128 unique certificate evaluations per candidate. This refines the **certificate**, not the integration grid. Repeated checks reuse candidate-local interval results.
4. At retained reference nodes in certified intervals, compute the original pointwise floor/exit/horizon cause and elapsed arithmetic. Immediate represented out-of-bounds/below-floor nodes can also be classified directly. A common distant-region clock/cause is never assumed. Near clock equality, accepted clean nodes, uncertain leaves, unbounded/rounding intervals and exhausted proof budgets use the original optimized resolver.

Every reference node is still processed, so a failed proof cannot discard probability mass. All ambiguous geometry and clock nodes fall back; the original choice function receives the same numerical accumulation stream. This is stronger reference fidelity than an empirical coarse/fine error estimate, but it **does not certify continuous probabilities between the reference's own nodes**. Nonmonotone branches in unresolved regions retain the reference's numerical limitations; the independent finer checks below expose that distinction.

The stated default/order8 reference node bounds remain208/404 per pass candidate, plus at most128 certificate evaluations and bounded cache lookups. Actual maximum observed requests were106 at order4 and206 in four order8 checks; maximum observed depth2 and certificate evaluations128. There is no cross-candidate/global cache. Actual selected-pass resolution is restored before outcome sampling. Method metadata explicitly reports original reference-node requests, actual full-resolver calls, fast terminals, proof work and fallback reasons; original diagnostic fields remain present.
