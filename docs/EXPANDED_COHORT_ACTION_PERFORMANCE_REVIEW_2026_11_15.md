Every finite/type/range/reference check remains. `same_input_snapshot` returns true for the identical immutable `PlayerInputs`/`InterpretedInputs` object; distinct objects still receive full document/contract comparison. Diagnostic serialization still uses the full structures. There is no global cache, approximation, reduced quadrature, reduced choice set or rating compression.
