# Image Studies Sources

The six vector illustrations in `image-studies.js` are original, hand-authored code for this project. Halftone, four-tone posterization and ordered dithering are performed locally on canvas. No image-generation model was used.

## Integration Notes

- This is a separate art-direction gallery; no game screen or save is modified.
- Original art uses generic basketball poses and objects, not a named real player's likeness.
- The edition switch demonstrates deterministic jersey variations and fictional labels. It does not call the game engine or imply generated players have actual portraits.
- Exported PNGs are opaque previews. Production cutouts, if selected, should use transparent backgrounds and retain a shared ink palette.
- Motion previews are explicitly triggered and honor reduced motion. Actual phase transitions must be driven by confirmed game state, not visual timers.
- Basketball subject illustrations should supplement existing data rather than replace fields or encode ratings through decorative detail.
